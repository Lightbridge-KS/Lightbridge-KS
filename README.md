# Lightbridge-KS


### 👨🏻 About Me

Hello there! I’m a diagnostic radiologist and software developer
building practical tools at the intersection of radiology, medical AI,
data science, and developer experience.

You are welcome to visit: [**🌱 My
Website**](https://lightbridge.netlify.app) and [**🍑 My
Blog**](https://lightbridge-blog.netlify.app).

### Projects

#### Agent Tools

- 🧩
  **[openclaw-notebook-tools](https://github.com/Lightbridge-KS/openclaw-notebook-tools)** -
  Jupyter Notebook plugin tools for OpenClaw agents: create, read, list,
  search, edit, and delete cells (Experimental).

#### Radiology Tools

**Apps**

- 🩻 **[designcter](https://github.com/Lightbridge-KS/designcter)** - CT
  protocol design and radiology calculator app.
- 🧾 **[radflow](https://github.com/Lightbridge-KS/radflow)** - CT/MRI
  protocol template generation and radiology calculator app.
- 🦋
  **[tirads-calc-py](https://github.com/Lightbridge-KS/tirads-calc-py)** -
  ACR TI-RADS calculator built with Python and Shiny.

**CLI**

- 🧰 **[slicer-cli](https://github.com/Lightbridge-KS/slicer-cli)** -
  Unofficial Python CLI for interacting with 3D Slicer Web Server.

#### Libraries & Packages

- 🇹🇭 **[thaipdf](https://github.com/Lightbridge-KS/thaipdf)** - R
  Markdown and PDF tooling for Thai-language documents.
- 🔎
  **[radreportparser](https://github.com/Lightbridge-KS/radreportparser)** -
  Regex-based parser for common radiology report text.

#### Notes & Books

- 🏗️
  **[software-design-explore](https://github.com/Lightbridge-KS/software-design-explore)** -
  Exploratory notes and book on software design.
- 🍳
  **[design-patterns-cookbook](https://github.com/Lightbridge-KS/design-patterns-cookbook)** -
  Cookbook-style design pattern reference.
- 📊
  **[radio-ds-notes](https://github.com/Lightbridge-KS/radio-ds-notes)** -
